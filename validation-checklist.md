Scientific Software Validation Checklist

This checklist represents a practical approach used when reviewing scientific software outputs.

Input Checks

- [ ] Confirm the correct dataset was loaded
- [ ] Check that required input values are present
- [ ] Check units and relevant parameters
- [ ] Confirm the input data is suitable for the workflow

Processing Checks

- [ ] Run the intended software workflow
- [ ] Confirm the software completes the processing
- [ ] Check for unexpected errors or behaviour
- [ ] Record important observations

Output Checks

- [ ] Confirm that the expected output is generated
- [ ] Review numerical results
- [ ] Review graphical results
- [ ] Check inversion or model results where applicable
- [ ] Check RMS/error behaviour where applicable
- [ ] Compare results with available reference or established results

Scientific Review

- [ ] Check whether the results appear reasonable based on relevant scientific knowledge
- [ ] Identify obvious inconsistencies
- [ ] Investigate unexpected results

Reproducibility

- [ ] Repeat the workflow where necessary
- [ ] Check whether similar inputs produce consistent results
- [ ] Record any differences observed

Documentation

- [ ] Record the validation observations
- [ ] Document unexpected behaviour
- [ ] Record relevant reproduction steps
- [ ] Communicate important findings to the technical team

Final Review

- [ ] Expected output generated
- [ ] Results reviewed
- [ ] Unexpected behaviour investigated
- [ ] Findings documented
- [ ] Validation completed
